# Bundled below (./maple/*.ttf, OFL) — Standard-Terminal-Font überall:
Maple Mono (16 Schnitte)
Install: mkdir -p ~/.local/share/fonts/maple &&
  cp configs/desktop/fonts/maple/*.ttf ~/.local/share/fonts/maple/ &&
  fc-cache -f ~/.local/share/fonts
Check: fc-list | grep -i maple
Fallback für Icons (Nerd-Font-Symbole) bleibt JetBrainsMono NFM (RPM/zypper).
